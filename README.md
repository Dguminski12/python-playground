# Python Playground

A small collection of command-line exercises used to practise core Python concepts and turn them into working programs.

## Exercises

- `input-test.py` - console input and output
- `password-checker.py` - conditional validation
- `random-number.py` - random values and control flow

## Run locally

```bash
git clone https://github.com/Dguminski12/python-playground.git
cd python-playground
python password-checker.py
```

This is intentionally a learning sandbox rather than a production application. Larger, portfolio-ready work is highlighted on my [GitHub profile](https://github.com/Dguminski12).
